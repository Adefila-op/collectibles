# ArtChain Frontend

React + Tailwind CSS frontend for the ArtChain Africa collectible art trading platform.

## Quick Start

```bash
npm install
npm start
```

App runs on `http://localhost:3000`

## Setup

1. Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

2. Configure API URL (should point to backend)

3. Install dependencies and start:
```bash
npm install
npm start
```

## Pages

- **Browse** - Discover artworks from collectors
- **My Collection** - Manage your owned artworks
- **My Offers** - View and manage all offers
- **Dashboard** - Track active swaps and approvals
- **Artwork Detail** - View artwork and place offers
- **Login/Register** - Authentication

## Features

✅ Browse and search artworks
✅ Detailed artwork pages
✅ Place standing offers
✅ Manage offers and swaps
✅ Real-time notifications
✅ Mobile responsive design
✅ Tailwind CSS styling

## State Management

Using Zustand for:
- Authentication state
- Artwork data
- Offers and swaps
